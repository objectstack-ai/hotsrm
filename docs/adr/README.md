改变某个决定，先读对应的记录；真要改，就写一份新的记录取代旧的，不直接改写旧记录的
「决定」部分。

## 写法

文件名 `NNNN-英文短名.md`，编号递增、不复用。每份记录包括：

- **状态**：提议中 / 已采纳 / 已被 NNNN 取代；
- **背景**：要解决什么问题，有哪些约束（引用平台文档或实测结果）；
- **决定**：一句话说清楚，再展开要点；
- **考虑过的方案**：每个方案的代价，为什么没选；
- **后果**：这个决定让哪些事变容易、哪些事变难，以及需要遵守的规则；
- **待验证**（如有）：做决定时还没验证、实现前必须确认的事。有了结论后在该条下追加
  「结果（日期）」一行，不改写「决定」部分。
- **补充说明**（如有）：决定之后新了解到的事实或口径澄清，不改变决定本身。
