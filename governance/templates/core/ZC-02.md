# 1　说明

1.1　本表汇总采购与供应商管理中需要审批的全部事项。各程序文件和管理办法附录中的审批权限与本表不一致的，以本表为准；修订时先改本表，再同步修订相关文件附录和 SRM 系统的审批流程配置。

1.2　本表所列金额档与审批人是依据现行文件整理的建议，须与{{org.superior}}的授权规定和公司现行授权文件核对后定稿。本表与 SRM 核心设计的审批矩阵（03 §12）一致：审批岗位的称谓按本公司叫法填写，系统中按岗位解析审批人。采购申请、付款等在 ERP 或 OA 中审批的事项只列出口径，不在 SRM 中配置。

1.3　所有审批适用下列通用规则：

a) 金额以单次事项的含税总金额计；同一需求在 {{param.split_purchase_window_months}} 个月内分批采购的，按累计金额确定审批层级，不得拆分规避；

b) 发起人不得审批本人发起的事项；审批人与发起人为同一人，或审批人与相关供应商存在关联关系的，由上一级审批人审批；

c) 寻源中有效报价少于 {{param.min_valid_quotes}} 家的，在相应定标权限基础上增加一级；

d) 「→」表示依次审批；「会签」表示并行审核、均须同意；

e) 关联交易按公司关联交易管理制度履行审议<!-- block:related-party-disclosure --><!-- /block -->程序；<!-- pack:soe -->达到「三重一大」标准的事项，在本表审批之前或之中履行集体决策程序；<!-- /pack -->以上均按公司现行规定执行；

f) 各级审批均在 SRM 系统中进行，系统审批记录为正式记录。
