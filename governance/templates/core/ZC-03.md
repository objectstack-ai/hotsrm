# 1　用途

1.1　本矩阵列出采购与供应商管理的主要风险、控制措施、执行方式、责任部门和规定出处，有三个用途：

a) **管理层**：了解每类风险由什么管住、谁负责；

b) **内控与审计**：作为采购内部控制评价和专项审计的检查清单，逐项抽查执行证据；

c) **信息化**：「系统」方式的控制即 SRM 系统必须实现并开启的控制，是系统验收和配置检查的依据。

1.2　控制方式分三种：**系统**，由 SRM 系统强制执行，人工无法绕过；**系统 + 人工**，系统提供流程、提醒或留痕，判断由人完成；**人工**，按文件规定人工执行，以记录为证。

1.3　「期次」是该控制随 SRM 系统哪一期上线：一期至四期为核心功能，「大宗包」「危化品包」「国企包」为对应扩展包的功能，上线期次在实施计划中确定。对应功能上线前，按{{doc.ZC-01}} 4.6.4 的过渡安排执行。

1.4　风险等级为固有风险的初步评估（高、中、低），由{{org.dept.procurement}}会同{{org.dept.audit}}每年复核。

# 3　使用与维护

3.1　内控评价和专项审计按本矩阵逐项抽查：「系统」控制检查系统配置和运行记录；「系统 + 人工」和「人工」控制抽查执行记录。

3.2　SRM 系统上线验收时，「系统」控制逐项测试通过方可上线；上线后控制配置的变更须经{{org.dept.procurement}}和{{org.dept.audit}}确认。

3.3　体系文件修订、新增或删除控制时，同步修订本矩阵；每年复核一次风险等级和控制有效性，结果报{{org.body.committee}}。
