# 1　目的

为规范供应商冻结、解冻、淘汰、列入黑名单及解除黑名单的条件、审批和执行，使处置有据、审批到位、执行同步、记录可查，及时隔离不合格和失信供应商，依据{{doc.QP-01}}第 6.9 条，制定本办法。

# 2　适用范围

2.1　本办法适用于公司及所属{{org.unit_term}}《合格供应商名录》内供应商的处置，以及已注册的潜在供应商的淘汰和列入黑名单。

2.2　供应商因信息变更导致主体变化、需要重新准入的，按{{doc.GL-04}}第 6.6 条执行；重新准入按{{doc.GL-01}}执行。

2.3　绩效结果、质量问题整改和资质异常的认定，分别按{{doc.QP-01}}第 6.7 条、第 6.8 条和{{doc.GL-01}}第 6.8 条执行；本办法规定据此启动处置的条件和程序。

# 4　术语和定义

{{doc.QP-01}}界定的术语适用于本办法。此外：

4.1　**处置**：对供应商的供货资格采取冻结、解冻、淘汰、列入黑名单或解除黑名单的措施。

4.2　**冻结**：暂停供应商全部或指定物资类别的供货资格。冻结可以解除，解冻后恢复冻结前的供货资格。

4.3　**淘汰**：终止与供应商的合格合作关系，供应商退出《合格供应商名录》。被淘汰的供应商不能直接恢复，重新合作须重新准入。

4.4　**黑名单**：因严重失信或违法违规，在规定期限内禁止供应商参加公司任何采购活动的名单。

4.5　**处置单**：在 SRM 系统中记载处置动作、范围、原因、生效日期和审批记录的电子单据，即{{doc.QR-14}}。

4.6　**在途业务**：处置生效前已签订、正在履行的合同和已下达的订单。

# 5　职责

5.1　**{{org.dept.procurement}}**：本办法的归口管理部门。{{org.position.category_manager}}负责提出处置建议、发起处置单；{{org.position.procurement_director}}负责审批；采购员负责按审批结果在 ERP 系统中同步冻结标志，通知供应商并处理在途业务。

5.2　**{{org.dept.quality}}、{{org.dept.hse}}**：对质量、安全环保事件提出处置建议，提供事实和证据。

5.3　**{{org.dept.finance}}**：对涉及资金风险的事项（如虚假改账、恶意索款）提出处置建议，按审批结果控制付款。

5.4　**{{org.dept.legal}}**：对处置涉及的合同终止、违约责任和争议提供法律意见。

5.5　**{{org.dept.oversight}}**：对商业贿赂、串通投标、提供虚假资料等违规事项开展调查，提出列入黑名单的建议；{{org.position.procurement_compliance}}负责列入黑名单的会签。

5.6　**{{org.position.general_manager}}**：审批淘汰、列入黑名单和解除黑名单。

# 6　管理要求

## 6.1　处置条件

6.1.1　供应商有下列情形之一的，可冻结其全部或相关物资类别的供货资格：

a) 资质异常持续超过 {{param.qualification_alert_freeze_days}} 日仍未恢复；

b) 连续 {{param.perf_d_exit_periods}} 期绩效评价为 D 级；

c) 发生重大质量事故或安全环保事件，或质量问题整改逾期未完成；

d) 涉嫌违法违规，正在接受公司或有关部门调查；

e) 严重违反合同约定，经催告仍未纠正。

6.1.2　供应商有下列情形之一的，予以淘汰：

a) 冻结后整改无效，或冻结原因消除前已无继续合作的必要；

b) 连续 {{param.inactivity_exit_months}} 个月与公司无交易；

c) 供应商主动申请退出，或已注销、吊销营业执照、进入破产程序；

d) 绩效评价结果按{{doc.QP-01}}第 6.7 条应予淘汰。

6.1.3　供应商有下列情形之一的，列入黑名单：

a) 提供虚假资料或伪造证照、检验报告；

b) 行贿或进行其他不正当利益输送，按{{doc.GL-05}}查实的；

c) 串通投标、围标，或以其他方式操纵采购结果；

d) 严重违约，给公司造成重大损失；

e) 对重大质量、安全环保事故负主要责任；

f) 冒用身份、伪造材料变更收款账户或以其他方式骗取付款。

6.1.4　处置的依据应当是查实的事实。处置建议应附证据材料，如绩效评价结果、整改单、检验报告、调查结论或合同违约记录；涉嫌违法犯罪的，同时移送有关机关。

## 6.2　处置的发起

6.2.1　处置一律通过 SRM 系统的处置单办理。{{org.position.category_manager}}根据第 6.1 条的条件，或相关部门的书面建议，在 SRM 系统中新建处置单（{{org.position.buyer_lead}}也可以新建，按第 6.3.1 条先经{{org.position.category_manager}}审批），写明处置动作、范围、原因和生效日期，并上传证据材料；处置单新建即提交审批。

6.2.2　处置动作应与供应商的当前状态相符：

a) 冻结全部物资类别，适用于合格供应商；冻结指定物资类别，适用于合格供应商的部分物资类别；

b) 解冻全部物资类别，适用于已冻结的供应商；解冻指定物资类别，适用于按物资类别冻结的合格供应商；

c) 淘汰，适用于潜在、合格和已冻结的供应商；

d) 列入黑名单，适用于合格、已冻结和已淘汰的供应商；

e) 解除黑名单，适用于黑名单内的供应商。

6.2.3　只有冻结和解冻可以指定物资类别；淘汰和列入黑名单一律针对全部物资类别。

6.2.4　同一家供应商同时只能有一张审批中的处置单。已有处置单在审批中的，应待其审批完成后再发起新的处置。

6.2.5　处置原因和生效日期在处置单被退回修改期间可以修改；供应商、处置动作、范围和物资类别提交后不得修改，需要改变的，驳回后重新发起。

## 6.3　审批

6.3.1　处置按附录 A 的权限审批：冻结、解冻由{{org.position.category_manager}}发起，{{org.position.procurement_director}}审批；处置单由{{org.position.buyer_lead}}发起的，先经{{org.position.category_manager}}审批，再按本款审批；淘汰、解除黑名单再经{{org.position.general_manager}}审批；列入黑名单经{{org.position.general_manager}}审批后，由{{org.position.procurement_compliance}}会签。

6.3.2　第一级审批人（{{org.position.category_manager}}发起时为{{org.position.procurement_director}}，{{org.position.buyer_lead}}发起时为{{org.position.category_manager}}）可以通过、驳回或退回修改；其后各级只能通过或驳回。审批意见应写明理由，驳回意见记入处置单。

6.3.3　处置单的发起人不得审批本人发起的处置单，各级审批人不得为同一人。审批人与发起人或前级审批人为同一人的，该次审批不予认可，由同级的其他人员重新审批；同级没有其他人员的，应先另行任命。

6.3.4　处置审批涉及{{doc.GL-05}}规定的利益冲突的，审批人应主动回避。

## 6.4　执行

6.4.1　处置单审批通过后，由 SRM 系统自动执行，处置单置为「已执行」：

a) 冻结全部物资类别：供应商状态转为「冻结」，其全部供货资格转为「暂停」；

b) 冻结指定物资类别：供应商状态不变，所选物资类别的供货资格转为「暂停」；

c) 解冻：恢复同一范围冻结时暂停的供货资格，恢复为冻结前的「合格」或「试供」；解冻全部物资类别的，供应商状态恢复为「合格」。冻结前已暂停的供货资格不因解冻而恢复；

d) 淘汰：供应商状态转为「淘汰」，其全部供货资格转为「暂停」；

e) 列入黑名单：供应商状态转为「黑名单」，其全部供货资格转为「暂停」；

f) 解除黑名单：供应商状态转为「淘汰」，不恢复任何供货资格。

6.4.2　处置执行后，SRM 系统通知发起人。采购员应在处置单的生效日期内，在 ERP 系统中同步设置或取消该供应商的冻结标志，并在处置单中注明同步情况；ERP 集成后由系统自动推送。

6.4.3　{{org.dept.procurement}}应在处置执行后书面通知供应商处置结果、原因及申诉方式；供应商门户上线后，经门户通知。

6.4.4　处置单被驳回的，不改变供应商的状态和供货资格。

## 6.5　处置的效力

6.5.1　**冻结**：冻结期间，不得向被冻结的供应商（按物资类别冻结的，为相应物资类别）发出新的寻源邀请，不得与其签订新的合同，不得新增采购。冻结不影响在途业务：已生效的合同、已下达的订单继续按合同约定履行，需要提前终止的，由{{org.dept.procurement}}会同{{org.dept.legal}}评估后按{{doc.GL-03}}办理。

6.5.2　**淘汰**：被淘汰的供应商退出《合格供应商名录》，不得被邀请参加寻源，不得签订新的合同。在途业务由{{org.dept.procurement}}逐项评估，履行完毕或按{{doc.GL-03}}终止。被淘汰的供应商重新合作，须按{{doc.GL-01}}重新提交准入申请、走完全部准入程序，不得以解冻或恢复的方式直接恢复。

6.5.3　**黑名单**：列入黑名单的供应商自处置执行之日起 {{param.blacklist_years}} 年内不得参加公司任何采购活动，其注册申请不予受理；在途业务由{{org.dept.procurement}}会同{{org.dept.legal}}评估，原则上依法终止，并追究违约责任。

6.5.4　与被淘汰或列入黑名单的供应商存在控制关系、或由同一实际控制人控制的企业，申请注册或准入时，{{org.dept.procurement}}应在资料审核中重点核查，确认不是规避处置的替身企业。

## 6.6　解冻与解除黑名单

6.6.1　冻结原因消除后，由{{org.position.category_manager}}发起解冻，处置单附整改验证、资质更新或调查结论等证明材料。

6.6.2　列入黑名单满 {{param.blacklist_years}} 年，或经查实列入黑名单的依据不成立的，可以解除黑名单。解除黑名单单独发起处置单，按附录 A 审批，不与其他处置合并办理。

6.6.3　解除黑名单后，供应商转为「淘汰」状态，不恢复任何供货资格；重新合作的，按{{doc.GL-01}}重新准入。

## 6.7　申诉

6.7.1　供应商对处置结果有异议的，可以在收到通知之日起 {{param.disposition_appeal_days}} 日内向{{org.dept.procurement}}提出书面申诉，并提供证明材料。

6.7.2　{{org.dept.procurement}}会同提出处置建议的部门复核；申诉理由成立的，按第 6.6 条发起解冻或解除黑名单；涉及廉洁问题的申诉，转{{org.dept.oversight}}处理。

## 6.8　记录与监督

6.8.1　处置单、证据材料、审批记录和执行结果，以 SRM 系统中的记录为准，长期保存。

6.8.2　{{org.dept.procurement}}每季度检查一次处置执行情况，重点核对 ERP 系统中的冻结标志与 SRM 系统中的供应商状态是否一致。

6.8.3　{{org.dept.oversight}}每年至少抽查一次处置记录，重点检查列入、解除黑名单的依据和审批。

# 7　信息化控制要求

本办法的下列要求在 SRM 系统中实施控制，系统配置应与本办法保持一致：

| 控制要求 | 本办法条款 | SRM 系统中的控制方式 |
|------------------------|------------|--------------------------------|
| 处置经处置单办理 | 6.2.1 | 供应商状态和供货资格只能由处置单的执行流程修改；新建处置单即提交审批 |
| 处置动作与供应商状态相符 | 6.2.2、6.2.3 | 新建处置单时校验动作与供应商当前状态；只有冻结、解冻可以指定物资类别，指定时必须选择物资类别 |
| 同一供应商只有一张审批中的处置单 | 6.2.4 | 供应商已有审批中的处置单时，不能再新建 |
| 按处置动作分级审批、黑名单会签 | 6.3.1 | 处置审批流程：发起人不是{{org.position.category_manager}}的，先由{{org.position.category_manager}}审批；{{org.position.procurement_director}}审批；淘汰、列入和解除黑名单加{{org.position.general_manager}}；列入黑名单再经{{org.position.procurement_compliance}}会签 |
| 发起人不审批本人的单据、各级审批人不同 | 6.3.3 | 每级通过后比对审批人与发起人、前级审批人，相同的该次通过不算数，通知审批人并重新审批 |
| 审批通过后自动执行 | 6.4.1 | 审批通过后由系统更新供应商状态和供货资格，记录冻结前的状态和冻结范围，处置单置为「已执行」 |
| 解冻只恢复同一范围冻结的资格 | 6.4.1 c) | 按冻结时记录的范围和冻结前状态恢复；淘汰、列入黑名单时清除冻结记录 |
| 冻结不影响在途、不能新签合同 | 6.5.1 | 已生效的合同不受影响；新建合同和合同生效时校验供应商为「合格」 |
| 淘汰只能重新准入 | 6.5.2、6.6.3 | 供应商状态机不允许从「淘汰」直接回到「合格」，只能经新的准入申请转为「准入中」 |
| 黑名单不得准入 | 6.5.3 | 注册受理时按统一社会信用代码（境外供应商按注册号）比对，命中黑名单自动不予受理 |
| 解除黑名单单独审批 | 6.6.2 | 解除黑名单是单独的处置动作，按最高一级审批，执行后供应商转为「淘汰」 |
